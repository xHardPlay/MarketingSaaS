# Simple Graphic Design Tool - MVP

This is a minimal viable product (MVP) for a graphic design tool that allows users to:
- Upload a background image
- Add text overlays with customizable position, size, and color
- Add logo overlays with adjustable size, position, and opacity
- Download the resulting image as PNG

## How to Use

1. Open `index.html` in a modern web browser (Chrome, Firefox, Safari).
2. Upload a background image using the file input.
3. Enter text in the text input field and adjust position, size, and color as needed.
4. (Optional) Upload a logo image and adjust its position, size, and opacity.
5. Click "Download Image" to save the composite image.

## Features

- Real-time preview on canvas
- Basic validation (file type and size)
- Responsive design (mobile-friendly)
- No server required - works entirely in the browser

## Limitations (MVP)

- Fixed canvas size (800x600)
- Basic text styling (color, size)
- No advanced features like layers, undo, or multiple logos
- Client-side only, no save/load functionality

## Deployment

For testing, open `index.html` locally. For online hosting, upload files to any static web server or use GitHub Pages with appropriate setup.
